# Requirements — "Elaborate" step (Mahārāja's 4-point write spec)

Status: **requirements only, not yet built.** Captured from a conversation with
Divakar on 2026-08-06, relaying instructions from H.H. Niranjana Swami.

## Background — the original 4-step workflow

Mahārāja's own words, given earlier and reconfirmed this session:

1. Take transcriptions individually
2. Create Summary in Evernote — **Evernote only**, no substitute method (his
   earlier phrasing "or by some other method" was retracted this session; our
   `summarize` tool is NOT an accepted substitute for this workflow)
3. Put Gopīparāṇadhana's commentary for analysis in Claude, then run my
   summary for analysis to extract points not covered in Gopīparāṇadhana
   Prabhu's commentaries — this is what `/compare` already does, unchanged
4. Write based on final output

This document specifies exactly what step 4 ("Write") should produce, per
Mahārāja's detailed instructions relayed 2026-08-06.

## Scope decision

**New tool, alongside `write-chapter-voiced` — not a replacement.** Both
exist; `write-chapter-voiced` is untouched. This is an additional script/
skill with a different output shape.

## Inputs

1. **Transcript** — the lecture's `*_restored.md`
2. **Evernote summary** — his real, hand-written Evernote summary. Not our
   auto-generated `summarize` output. Two candidate paths to get this
   summary are still being tested (see "Open: Evernote path" below) — neither
   is finalized yet.
3. **Comparison notes** — the existing `/compare` output (`*_comparison.md`),
   unchanged, still generated by comparing the Evernote summary against
   Gopīparāṇadhana Dāsa's Vol.1 commentary.

## Output — Mahārāja's 4 points (verbatim, given in his original casing)

Inputs feeding this: the comparison notes generated in step 3, plus the
Evernote summary.

1. PROVIDE THE SPEAKER'S ELABORATION CONTEXTUALLY FROM HIS PRESENTATION
2. IN OTHER WORDS DON'T GIVE A SUMMARY BUT GIVE AN EDITED VERSION OF THE
   ABOVE POINT 1
3. FIND OTHER EXAMPLES USED BY THE SPEAKER ON THIS TOPIC WITHIN THE CONTEXT
   OF HIS PRESENTATION FROM HIS PREVIOUS LECTURES OR BOOKS AND LIST THEM
   SEPARATELY
4. SUGGEST THE BEST VERSION FOR ELABORATING ON THIS TOPIC, PLEASE LIST THESE
   SUGGESTIONS AT THE BOTTOM OF THE OUTPUT, IF MORE THAN ONE TOPICS ARE
   EXTRACTED PLEASE PROVIDE AN EXAMPLE OF EACH

### Interpretation, confirmed this session

- **Point 1+2**: not a compressed summary — an *edited* rendition of what he
  actually said in the presentation. Trim/clean, but keep his real words and
  structure. This is the bulk of the output.
- **Point 3**: cross-reference the same topic against **his books only** —
  explicitly narrowed from "previous lectures or books" to books-only this
  session. Corpus is ready, on Divakar's local disk (exact paths not yet
  given).
- **Point 4**: closing section, suggested best elaboration per topic, with
  one example per topic if the lecture covers more than one.
- **Voice**: first-person throughout — Mahārāja is the author, same standing
  rule as `write-chapter-voiced`. Not third-person description of his
  teaching.
- **Unit of output**: **one combined file per lecture**, not one file per
  topic. If a lecture covers multiple topics, points 3 and 4 each list
  multiple entries (one per topic) inside that single output file — the
  file itself doesn't split per topic.

### Evernote summary path — two candidates being tested, neither decided

Source audio is always a Zoom recording of the class. Two ways to get the
Evernote summary from it, to be tested against each other for quality:

- **Path 1**: drop the raw Zoom audio directly into Evernote, let Evernote's
  own built-in transcribe/summarize feature run on it. (This is what the
  `evernote-audio-note` skill already does — uploads local audio into a new
  Evernote note and triggers Evernote's transcribe/summarize.)
- **Path 2**: feed Evernote our own pipeline's already-cleaned,
  verse-restored transcript instead of raw audio, and let Evernote only
  summarize (not transcribe) that already-correct text.

Expectation going in: Path 2 should produce a better summary since Sanskrit/
IAST is already correct in our transcript, whereas Path 1 relies on
Evernote's own (likely weaker on Sanskrit) speech-to-text. Not yet tested —
plan is to run both on the same lecture and compare.

Until this is resolved, there's no fully automated way to get the Evernote
summary into this pipeline — it may still require manual copy/paste per
lecture, same as the 4 sample summaries used to build `summarize`.
